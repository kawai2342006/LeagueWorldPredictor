HOW IT WORKS

由預測，到驗證。

按一次更新，讀取最新可用資料。已完賽比分會更新戰績與路線；個人回報待市場正式結算。未知對手保留待公布。報價會有快取或市場延遲。

  1. 點選勝方

    揀隊伍、輸入模擬投入並保存，記錄當刻賠率。

  2. 等比賽結果

    按更新同步完賽比分與正式結算結果，或在「賽程管理」手動錄入；作廢場次會退回投入，不影響命中率。

  3. 回看表現

    在「回報分析」查看累計盈虧、ROI 同命中率。

  4. 繼續下一輪

    按更新讀取已上架對賽；戰績組不明時可在「資料狀態」指定對賽格。瑞士輪並非固定淘汰樹，唔會由預測自動產生下一輪。

賠率係 Polymarket 頁面顯示嘅十進制倍數，並非保證回報。每隊市場價格可能有價差，顯示百分比唔一定相加等於 100%。個人記錄只存於此電腦，無需登入。更新只讀取 Polymarket 公開資料，唔會上傳你嘅預測。首輪後亦可手動更新賠率；可按「更新 Polymarket」擷取公開接口嘅最新可用報價、已上架對賽及正式結算賽果。

個人記錄保存在這個瀏覽器

預測、投入、筆記及歷史賠率使用 localStorage 儲存，不會隨資料更新上傳；其他電腦的使用者有各自的記錄。

請用相同瀏覽器、使用者設定檔及網址開啟。清除網站資料、使用無痕模式或轉換裝置可能令記錄不再可用；請定期匯出個人備份。共用同一瀏覽器設定檔的人會共用記錄。

Windows 版與 GitHub Pages 是不同儲存位置。搬到網頁版時，請先匯出備份，再在新網址還原一次。
